# Portfolio redesign implementation plan

> **For agentic workers:** implement in this task; verify the final rendered page before completion.

**Goal:** Replace the game/neon portfolio with the user's requested Apple-inspired, minimalist, futuristic visual direction.

**Approach:** Keep the static HTML/CSS/JavaScript architecture and existing factual content. Use a silver/white canvas, graphite sections, system sans typography, blue functional accents, and a single dimensional platform sculpture. Large project presentations lead into a restrained career timeline and contact section. No added runtime dependencies.

## Design choices

- Colors: porcelain `#f5f5f7`, white `#ffffff`, graphite `#1d1d1f`, gray `#6e6e73`, blue `#0071e3`, night `#08090b`.
- Type: system sans with Helvetica/Arial fallback, tightly spaced large headings; the same family at calm body sizes.
- Signature: layered metal plates represent a shared core across Android, iOS, and the web; the rest of the page stays quiet.
- Content: concise writing grounded in the existing portfolio; abstract product illustrations are labeled, and the CCTV image is the existing real dashboard.
- Scope: homepage redesign; keep printable resume and document reader available, preserve unrelated existing JS edits as unloaded legacy files.
